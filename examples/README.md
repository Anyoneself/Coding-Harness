# Examples

- `production_agent_demo.py`: local production-mechanism demo and evaluation CLI.
- `langgraph_investment_demo.py`: role-aware LangGraph orchestration example.
- `legacy/`: earlier standalone model, memory, and embedding experiments.

Run examples from the repository root:

```bash
python -m examples.production_agent_demo run
python -m examples.langgraph_investment_demo
```
